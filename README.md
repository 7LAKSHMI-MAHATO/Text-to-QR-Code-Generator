# 🔳 Text to QR Code Generator

A simple and user-friendly web application that generates a QR code from any text entered by the user.

The application uses **HTML, CSS, JavaScript, and the QRCode.js library** to generate QR codes directly in the browser.

## ✨ Features

- 🔤 Enter any text
- 🔳 Generate a QR code instantly
- 🔄 Generate a new QR code by entering different text
- ⚠️ Shows an alert when the input field is empty
- 📱 Simple and responsive interface
- 🎨 Clean and minimal user interface
- ⚡ QR code generation happens directly in the browser

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- QRCode.js
- CDN
